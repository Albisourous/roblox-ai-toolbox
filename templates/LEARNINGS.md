# Roblox AI toolbox learning log

Record one generic, evidence-backed lesson per line. Use an allowed area and mark the status as observed or verified with a Creator Docs URL.

Allowed areas: `ads`, `game-design`, `monetization`, `economy`, `retention-growth`, `metrics`, `publishing`, `studio-tooling`, `agent-workflow`, `getting-started`.

Format:

```text
- [area] lesson. Evidence: what happened. Status: observed | verified <docs URL>. Added: YYYY-MM-DD. Harvested: no
```

Example:

```text
- [studio-tooling] Play loaded an older script after sync. Evidence: the Edit and Server fingerprints differed before a fresh start. Status: observed. Added: 2026-10-31. Harvested: no
```

Never record secrets, player data, user IDs, private links, or Robux revenue.
